API Quittances

Contrat documentaire — version 0.0.1-demo · 5 novembre 2026

Contrat OpenAPI YAML · Contrat OpenAPI JSON

Cette page décrit les routes ; elle ne lance aucune requête. Pour les appeler, utiliser la collection Postman fournie. Signature par certificat local de test et emails capturés par Mailpit.

Authentification : Authorization: Bearer JWT. Les permissions sont contrôlées par le serveur. Ouvrir une ligne pour consulter les détails.

GET /api/v1/systeme/etatÉtat du service

Permissions et fonctionnement

Réponse applicative minimale. Ne constitue pas une vérification exhaustive de PostgreSQL et des services externes.

Réponses HTTP

  • 200 — Résultat attendu
  • 500 — Erreur interne.

  • 401 — JWT absent, invalide ou expiré.

  • 500 — Erreur interne.

POST /api/v1/quittancesPréparer un brouillon

Permissions et fonctionnement

Bailleur propriétaire uniquement. Consulte les sources métier ; ne crée aucun paiement. Le document reste non signé et non émis.

Corps JSON

{
  "bailId": "{{bailId}}",
  "periodeDebut": "{{periodeDebut}}",
  "periodeFin": "{{periodeFin}}"
}

Réponses HTTP

  • 201 — Résultat attendu
  • 400 — Entrée invalide.
  • 401 — JWT absent, invalide ou expiré.
  • 403 — Action non autorisée.
  • 409 — Conflit métier, de version, de statut ou d’intégrité.
  • 422 — Règle métier non satisfaite.
  • 500 — Erreur interne.
  • 503 — Dépendance ou configuration indisponible.

POST /api/v1/quittances/{id}/envois-mailpitEnvoyer dans Mailpit

Permissions et fonctionnement

Bailleur propriétaire uniquement. Document DEMO-QT émis et actif. Destinataire fictif généré côté serveur. Même requeteId : pas de nouveau SMTP ; résultat existant. Réessai autorisé seulement après échec avant transmission et délai de 30 secondes.

Corps JSON

{
  "requeteId": "{{requeteEnvoiId}}",
  "confirmation": true
}

Réponses HTTP

  • 200 — Résultat attendu
  • 400 — Entrée invalide.
  • 401 — JWT absent, invalide ou expiré.
  • 403 — Action non autorisée.
  • 404 — Document absent ou hors périmètre.
  • 409 — Conflit métier, de version, de statut ou d’intégrité.
  • 429 — Réessai trop rapproché.
  • 500 — Erreur interne.
  • 503 — Dépendance ou configuration indisponible.
  • 202 — La même tentative est déjà en cours.

Paramètres

  • id (path, string)
